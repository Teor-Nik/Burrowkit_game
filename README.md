# Burrowkit

A turn-based dungeon crawler written in Python, inspired by classic roguelikes.

A loyal partner follows you through the depths and fights at your side. Manage your HP, hunger and limited move uses, gather berries and items along the way, and watch your kit grow into a fox, and then a legend, as you descend.

## Features
PLANNED: 
- Generated floors with rooms, corridors and stairs
- Turn-based movement and combat
- A partner companion
- Monsters that chase you
- A 4-move system with limited uses, plus a hunger meter
- A fox that grows through three stages as it levels up
- Save and load using JSON

## About this project

This is a personal learning project to build Python skills. It follows a model-view-controller structure, with game logic kept separate from the display, and uses type hints, docstrings, pytest and mypy throughout.
